메뉴 만들기 — while True + break

지금까지 만든 add_note, find_note, delete_note는 코드 안에 박혀서 한 번 실행하면 정해진 동작만 해. 이번 레슨에서는 "종료를 선택할 때까지 계속 메뉴를 보여주는" 프로그램으로 묶는다.

왜 필요할까? 지금까지 만든 함수들은 "재료"였고, 메뉴 루프는 그 재료들을 실제 사용자가 쓸 수 있는 하나의 프로그램으로 조립하는 마지막 단계다. ai-dev-team에서도 에이전트가 "다음에 뭘 할지"를 계속 반복해서 선택하는 구조가 결국 이 패턴이다.

핵심 문법 1 — while True

while True:는 조건이 항상 참이라 "무조건 반복"한다. 대신 안에 반드시 break(반복을 그 자리에서 즉시 멈추는 명령)로 빠져나갈 방법을 만들어줘야 한다. 

while True:
    choice = input("종료하려면 4: ").strip()
    if choice == "4":
        break

핵심 문법 2 — if / elif / else 체인

조건이 여러 개일 때는 elif("else if"의 줄임)로 이어 붙인다. 위에서부터 순서대로 검사해서 맞는 조건 하나만 실행된다. 

if choice == "1":
    ...
elif choice == "2":
    ...
elif choice == "3":
    ...
elif choice == "4":
    break
else:
    print("잘못된 선택이에요")
Primary source Python 공식 튜토리얼 — break 문 — break가 반복문을 어떻게 즉시 멈추는지 확인해봐.

확인 퀴즈

1. 조건 없이 무조건 반복하는 while 문은?
2. 반복문을 그 자리에서 즉시 멈추는 키워드는?
3. "else if"를 줄여 쓴 파이썬 키워드는?

직접 해보기

notes_app.py를 메뉴 프로그램으로 다시 짜보자:

  1. 맨 위에서 notes를 한 번 불러오는 부분(try/except)은 그대로 둔다
  2. 그 아래를 while True: 블록으로 감싼다
  3. 매 반복마다 "1. 추가 / 2. 찾기 / 3. 삭제 / 4. 종료" 같은 메뉴를 input()으로 보여준다
  4. if/elif/else로 선택에 따라 add_note, find_note, delete_note를 호출한다 (제목/내용 입력받는 부분은 레슨 3~4에서 만든 while 검증을 그대로 재사용하면 된다)
  5. "4. 종료"를 선택하면 json.dump로 저장하고 break한다
  6. 레슨 5에서 테스트용으로 넣었던 find_note(notes, "6"), delete_note(notes, "6") 같은 하드코딩된 호출은 이제 지워도 된다 (메뉴로 대체되니까)

한 번에 다 하려 하지 말고, 메뉴 틀(선택지 보여주고 4번으로 종료)부터 만들고, 그다음 1번(추가)만 연결해서 테스트하고, 그다음 2번, 3번 순서로 하나씩 붙여나가는 걸 추천해. 막히면 Claude에게 바로 물어봐.
