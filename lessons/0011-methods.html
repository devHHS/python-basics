메서드 — 클래스 안에 "동작"을 정의하기

레슨 10에서 만든 Note는 title, content라는 데이터만 가지고 있다. 지금까지 뭔가 "하려면" n.content[:10]처럼 바깥에서 직접 다뤄야 했다. 메서드(method)는 그 동작을 클래스 안에 넣어서, 데이터와 그 데이터로 할 일을 한 군데 묶어두는 방법이다.

왜 필요할까? ai-dev-team에서 에이전트들이 주고받을 데이터 클래스(Pydantic 모델)도 종종 자기 자신을 다루는 메서드를 가진다 — "이 상태가 유효한가?", "요약을 만들어줘" 같은 것. 메서드 문법에 먼저 익숙해지면 그때 자연스럽게 읽힌다.

핵심 개념 — self가 있는 함수

메서드는 그냥 클래스 안에 정의된 함수다. __init__도 사실 메서드의 하나였다 — "인스턴스가 만들어질 때"라는 특별한 순간에 자동으로 불릴 뿐, 문법은 똑같다: 

class Note:
    def __init__(self, title, content):
        self.title = title
        self.content = content

    def preview(self):
        return self.title + ": " + self.content[:10]

뜯어보면:

  • def preview(self): — 클래스 안에서 정의했으니 메서드다. 첫 매개변수는 항상 self (관례적 이름일 뿐이지만 거의 모두가 이 이름을 쓴다).
  • self.title, self.content — __init__에서 저장해둔 이 인스턴스의 값을 그대로 읽어온다.
  • 메서드도 함수니까 return으로 값을 돌려줄 수 있다.

부를 때는 __init__과 마찬가지로 self를 직접 넘기지 않는다:

n = Note("장보기", "우유, 계란, 빵, 버터")
n.preview()   # "장보기: 우유, 계란, 빵"

n.preview()라고 쓰면 파이썬이 알아서 Note.preview(n)으로 바꿔 부른다 — 점 앞의 n이 자동으로 self 자리에 들어간다. __init__이 Note(...)를 부를 때 self를 안 넘겨도 됐던 것과 같은 규칙이다.

매개변수를 더 받는 메서드도 만들 수 있다 — self 뒤에 추가하면 된다: 

    def rename(self, new_title):
        self.title = new_title
n.rename("장보기 목록")   # self=n, new_title="장보기 목록"
n.title                   # "장보기 목록"

2. n.preview()를 실행하면 파이썬이 실제로 부르는 것은?
3. def rename(self, new_title): 를 n.rename("새 이름")으로 부르면, new_title에 들어가는 값은?

힌트: 메서드는 __init__과 같은 들여쓰기 위치(클래스 블록 안, 나란히)에 정의해야 한다. 레슨 10에서 겪었던 실수 — 인스턴스 생성 코드를 __init__ 안에 잘못 넣었던 것 — 을 떠올리며 들여쓰기를 확인해봐.
