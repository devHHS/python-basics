함수(function)로 코드 정리하기

지금까지 짠 note.py는 위에서 아래로 코드가 쭉 나열되어 있어. 노트를 추가하는 로직, 저장하는 로직, 출력하는 로직이 전부 한 덩어리로 뒤섞여 있지. 이 레슨에서는 그 중 "노트 하나를 추가하는" 부분을 함수로 떼어내는 법을 배운다.

왜 필요할까? 나중에 ai-dev-team에서 여러 에이전트가 협업하는 코드를 짤 때, 코드가 지금보다 훨씬 커진다. 그때 "의미 단위로 이름 붙여 나누는 능력"이 없으면 코드를 읽을 수도, 고칠 수도 없게 된다. 함수는 그 능력의 가장 작은 단위다.

핵심 문법

def로 함수를 정의하고, 함수 안에서 만든 결과를 밖으로 돌려주고 싶으면 return을 쓴다.

def add_note(notes, title, content):
    note = {"title": title, "content": content}
    notes.append(note)
    return notes

괄호 안의 notes, title, content는 매개변수(parameter) — 이 함수가 일할 때 필요한 재료를 밖에서 받아오는 이름표다. 함수를 실제로 쓸 때는 이렇게 호출한다: 

notes = add_note(notes, title, content)
Primary source Python 공식 튜토리얼 — Defining Functions — 함수 정의 문법을 5분 안에 훑어볼 수 있는 공식 문서. 기본값 인자 등 다음 레슨에서 쓸 내용도 여기 있다.

3. 정의해둔 add_note 함수를 실제로 실행하는 코드는?
