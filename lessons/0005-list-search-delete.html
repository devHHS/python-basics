리스트에서 검색하고 지우기

지금까지는 노트를 추가만 했지, 특정 노트를 찾거나 지우는 방법은 없었어. 이번 레슨에서는 제목으로 노트를 찾는 함수와 지우는 함수를 만든다.

왜 필요할까? "리스트에서 조건에 맞는 걸 찾기"는 정말 자주 쓰는 패턴이다. 나중에 ai-dev-team에서 "이 조건에 맞는 작업/에이전트를 찾아라" 같은 로직도 결국 같은 모양이다.

핵심 문법 1 — 인덱스와 함께 순회하기: enumerate()

지금까지 for n in notes:로 원소만 꺼냈다면, enumerate()를 쓰면 "몇 번째인지(인덱스)"와 "원소" 둘 다 꺼낼 수 있다. 지우려면 원소가 몇 번째에 있는지(인덱스)가 필요하다. 

for i, n in enumerate(notes):
    print(i, n["title"])

핵심 문법 2 — 찾기

def find_note(notes, title):
    for n in notes:
        if n["title"] == title:
            return n
    return None

찾으면 그 자리에서 바로 return해서 함수를 끝낸다. 끝까지 못 찾으면 None(값이 없다는 뜻)을 돌려준다.

핵심 문법 3 — 지우기

def delete_note(notes, title):
    for i, n in enumerate(notes):
        if n["title"] == title:
            del notes[i]
            return notes
    return notes

del notes[i]는 리스트의 i번째 원소를 지운다. 인덱스를 알아야 하니까 여기선 enumerate()가 필요하다.

Primary source Python 공식 문서 — enumerate() — enumerate가 정확히 뭘 돌려주는지 확인해봐. (인덱스, 원소) 쌍을 하나씩 만들어준다는 걸 기억하면 충분하다.

확인 퀴즈

1. 리스트를 순회하며 인덱스도 같이 얻고 싶을 때 쓰는 함수는?
2. 리스트에서 특정 인덱스의 원소를 지우는 코드는?
3. 찾는 값이 리스트에 없을 때 함수가 돌려줘야 할 값은?

직접 해보기

notes_app.py에 (또는 실험하고 싶으면 새 파일에) 다음을 추가해봐:

  1. find_note(notes, title) 함수를 정의한다
  2. delete_note(notes, title) 함수를 정의한다
  3. 맨 아래 print(notes) 다음에, 존재하는 제목과 존재하지 않는 제목 둘 다로 find_note를 호출해서 결과를 print해본다 (하나는 노트가 나오고, 하나는 None이 나와야 한다)
