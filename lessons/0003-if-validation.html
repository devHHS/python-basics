빈 입력값 막기 — if문

지금 notes_app.py는 제목/내용에 그냥 엔터만 쳐도(빈 문자열이어도) 노트로 저장해버려. 쓸모없는 빈 노트가 쌓이는 걸 막으려면, "조건에 따라 다르게 행동하는" 방법이 필요하다.

왜 필요할까? "사용자가 이상한 값을 넣었을 때 어떻게 할지"는 모든 프로그램이 마주치는 문제다. 지금은 빈 문자열 하나지만, 나중에 ai-dev-team에서 에이전트가 받은 입력이 형식에 안 맞을 때도 똑같은 판단(조건 → 분기)이 필요하다.

핵심 문법

if로 조건을 검사하고, 조건이 참(True)일 때만 그 아래 들여쓴 코드를 실행한다.

if title == "":
    print("제목을 입력해야 해요")

파이썬에서는 빈 문자열 ""이 거짓(False)처럼 취급된다. 그래서 if title: 만 써도 "title이 비어있지 않으면"이라는 뜻이 된다. 그리고 사용자가 실수로 공백만 입력(" ")했을 때도 걸러내려면, 앞뒤 공백을 지우는 .strip()을 같이 쓴다. 

title = input("제목이 뭔가요: ").strip()
if title == "" or content == "":
    print("제목과 내용을 모두 입력해야 해요")
else:
    notes = add_note(notes, title, content)
Primary source Python 공식 문서 — Truth Value Testing — 어떤 값들이 파이썬에서 "거짓"으로 취급되는지 정리한 표. "", 0, [] 등이 모두 거짓이라는 걸 확인해봐.

확인 퀴즈

1. 파이썬에서 빈 문자열 ""은 조건문에서 어떻게 취급될까?
2. 문자열 앞뒤의 공백을 지우는 메서드는?

직접 해보기

notes_app.py를 열어서:

  1. title, content를 받을 때 .strip()을 붙인다
  2. 둘 중 하나라도 비어있으면 add_note를 호출하지 말고 안내 메시지만 출력하도록 if/else로 분기한다
  3. 일부러 제목을 빈 칸으로 실행해보고, 저장되지 않는지 확인한다
