코드를 여러 파일로 나누기 — import

지금 notes_app.py 하나에 함수(add_note, find_note, find_all_by_title, update_note, delete_note)와 메뉴 루프, 파일 저장 코드가 전부 들어있어. 파일 하나가 점점 길어지고 있지. 이번 레슨에서는 "노트 관련 함수들"만 따로 파일로 빼고, notes_app.py에서는 그 파일을 가져다 쓰기만 하는 법을 배운다.

왜 필요할까? ai-dev-team에서는 에이전트마다 자기 파일이 있고, 서로 필요한 걸 import해서 쓴다. "함수는 한 파일에, 그 함수를 쓰는 코드는 다른 파일에" 나누는 감각이 그 구조를 이해하는 첫걸음이다.

핵심 개념 — 모듈(module)과 import

파이썬에서는 .py 파일 하나가 곧 모듈(module)이야. 다른 파일에 있는 함수를 쓰고 싶으면 import로 그 파일(모듈)을 가져오면 된다. 방법은 두 가지야: 

# 방법 1: 필요한 함수만 이름으로 콕 집어서 가져오기
from notes import add_note, find_note

add_note(notes, title, content)   # 바로 이름으로 부른다

# 방법 2: 파일(모듈) 전체를 가져와서, 그 안의 함수를 "모듈이름.함수이름"으로 부르기
import notes

notes.add_note(notes_list, title, content)   # notes. 을 붙여서 부른다

파일 이름이 곧 모듈 이름이 된다 — notes.py를 가져올 땐 .py 없이 notes라고만 쓴다.

주의: 이번 레슨에서 모듈 이름은 notes인데, 우리 코드에는 노트 리스트를 담는 변수도 notes야. 이름이 겹쳐도 파이썬은 헷갈리지 않지만(모듈과 변수는 다른 이름 공간에 있음), 사람이 읽을 땐 헷갈릴 수 있다는 걸 기억해두자. 그래서 이번 레슨에서는 "방법 1"(필요한 함수만 이름으로 가져오기)을 쓸 거야 — 지금 코드를 거의 그대로 두고 맨 위에 한 줄만 추가하면 되기 때문이다.

Primary source Python 공식 튜토리얼 — Modules — 모듈이 무엇이고 import가 실제로 무슨 일을 하는지 확인해봐.

확인 퀴즈

1. notes.py에 있는 add_note를 notes_app.py에서 쓰려면?
2. from notes import add_note 라고 썼을 때, add_note를 부르는 방법은?
3. import notes 라고만 썼을 때(from 없이), add_note를 부르는 방법은?

직접 해보기

노트 관련 함수들을 notes.py라는 새 파일로 옮겨보자 (프로젝트 폴더에, notes_app.py와 같은 위치):

  1. 새 파일 notes.py를 만든다
  2. notes_app.py에서 add_note, find_note, find_all_by_title, update_note, delete_note, search_title 함수 정의를 전부 잘라내서 notes.py로 옮긴다 (함수 위 한국어 주석도 같이 옮기면 좋다)
  3. notes_app.py 맨 위, import json 아래에 from notes import add_note, find_note, find_all_by_title, update_note, delete_note, search_title를 추가한다
  4. 실행해서(python3 notes_app.py) 이전과 똑같이 작동하는지 확인한다 — 추가/찾기/삭제/수정 다 테스트

힌트: 옮기다가 NameError: name 'add_note' is not defined 같은 에러가 나면, import 줄을 빼먹었거나 함수 이름을 잘못 옮겨적었을 확률이 높다. 에러 메시지의 함수 이름을 그대로 검색해서 어디서 안 보이는지 찾아보자.
