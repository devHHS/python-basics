파일이 없을 때 대비하기 — try / except

지금까지 만든 코드는 notes.json이 이미 존재한다고 가정하고 있어. 근데 이 프로그램을 처음 실행하는 사람(또는 처음 실행하는 너 자신의 새 컴퓨터)에게는 그 파일이 없어. 그러면 open("notes.json", "r")에서 바로 프로그램이 멈춰버린다.

왜 필요할까? "예상 밖의 입력이나 상태에서도 프로그램이 무너지지 않게 만드는 것"은 소프트웨어 엔지니어링의 기본기다. 나중에 ai-dev-team에서 에이전트가 외부 파일/API를 다룰 때도 "이게 없으면?", "이게 이상하면?"을 항상 대비해야 한다. 지금 이 작은 케이스로 그 감각을 처음 익힌다.

핵심 문법

파이썬은 "일단 시도해보고, 안 되면 처리한다(try, 안 되면 except)"는 방식을 쓴다. 

try:
    with open("notes.json", "r") as f:
        notes = json.load(f)
except FileNotFoundError:
    notes = []

try: 블록 안의 코드를 먼저 실행해본다. 그러다 FileNotFoundError(파일이 없다는 에러)가 나면, 프로그램이 멈추는 대신 except FileNotFoundError: 블록으로 넘어가서 그 안의 코드를 실행한다.

Primary source Real Python — Python Exceptions: An Introduction — 예외(에러)가 뭔지, try/except가 왜 필요한지 친절하게 설명하는 글. "Errors vs Exceptions" 섹션만 읽어도 충분하다.

확인 퀴즈

1. 코드를 "일단 시도"할 때 쓰는 키워드는?
2. 파일이 없을 때 발생하는 에러의 이름은?

1번 문제의 실제 키워드는 try이고, 선택지는 밑줄을 채워 길이를 맞춘 것뿐이야 (try_ → try).

직접 해보기

새 파일 notes_app.py를 만들어서 다음을 해봐:

  1. note.py에서 import json과 add_note 함수를 그대로 가져온다
  2. notes.json을 읽는 부분을 try/except FileNotFoundError로 감싸서, 파일이 없으면 notes = []로 시작하게 만든다
  3. 일부러 notes.json 파일을 지우거나 이름을 바꿔보고, 프로그램이 안 터지고 새 리스트로 시작하는지 확인한다
