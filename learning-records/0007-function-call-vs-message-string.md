# 함수 호출과 출력 메시지를 섞으면 안 된다는 것 이해

이전 세션에서 `find_note(f"{notes}, {title}을 성공적으로 찾았습니다")`처럼 함수 인자와 안내 메시지를 하나의
f-string으로 합쳐서 `TypeError: missing 1 required argument`가 났던 걸 이번 세션에 다시 짚었다.
처음 고칠 때는 반대로 함수 호출 자체를 지워버리고 메시지만 남겼는데, "3.삭제를 선택해도 실제로는 아무것도
안 지워진다"는 걸 질문으로 짚어주자 스스로 필요성을 이해하고, 함수 호출과 안내 메시지를 각각 별도의
`print`문 두 줄로 분리해서 고쳤다.

**Implications**: "함수 호출(로직) vs 출력(표시)은 분리해야 한다"는 감각이 아직 확실히 자리잡진 않았음 —
비슷한 실수가 다시 나오면 이번처럼 "이 메뉴가 진짜로 동작하는 척만 하는지" 같은 구체적 시나리오로 질문하는
게 효과적이었다. 아직 다루지 않은 개선점: `find_note`가 `None`을 돌려줘도 무조건 "성공적으로 찾았습니다"라고
나오는 것 — 다음에 `if`로 None 체크하는 것도 자연스러운 다음 스텝.
