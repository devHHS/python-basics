# if 검증 → while 재입력 루프로 확장

레슨 3에서 `if title == "" or content == ""`로 빈 입력을 걸러내는 것(1회 검사)을 만들었고,
레슨 4에서 이를 `while title == "":` / `while content == "":` 형태로 바꿔 "유효할 때까지 계속 재입력받기"로 확장했다.
직접 여러 번 빈 값을 넣어 무한 루프처럼 반복되다가 값을 입력하면 빠져나오는 것을 실행으로 확인했다.
복사 과정에서 생긴 메시지 오타(제목/내용 안내 문구가 뒤바뀜)도 스스로 발견해 고쳤다.

**Implications**: if(1회 조건)와 while(조건이 참인 동안 반복)의 차이를 실전에서 구분해서 쓸 수 있음.
다음 레슨은 이 위에 쌓을 수 있는 것 — 예: 여러 함수로 더 쪼개기(load_notes/save_notes/prompt_note),
또는 리스트 검색/삭제(특정 제목의 노트 찾기) 정도가 적절한 난이도.
