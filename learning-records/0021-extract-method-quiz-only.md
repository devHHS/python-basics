# 0021 — DRY/함수 추출 개념은 확인, 실습은 보류

## 무엇을 했나
레슨 18(함수를 작게 쪼개는 이유)의 퀴즈(DRY, Extract Method, 순수 함수 vs 출력 함수)를 모두 맞혔다.
다만 "직접 해보기" 실습(`notes_app.py`의 중복 코드를 `print_notes` 함수로 뽑기)은 컨디션이 안 좋다는
이유로 본인이 아닌 Claude가 대신 수행했다.

## 확인한 것과 확인하지 못한 것
- **확인됨**: DRY 원칙, Extract Method의 목적(가독성/중복 제거/에러 예방), 순수 함수와 출력(side
  effect) 함수의 테스트 가능성 차이 — 퀴즈로 개념 이해는 확인.
- **확인 안 됨**: 이 개념을 실제 코드에서 스스로 적용하는 능력. "코드를 대신 짜주지 않는다"는 이
  폴더의 핵심 원칙에서 이번 세션만 예외를 둔 것이므로, 이번 리팩터링 완료를 storage strength의
  증거로 보면 안 된다.

## Implications
- 다음 세션에서 비슷한 중복 코드 리팩터링(예: 메뉴 4번 "Delete by ID"/"Delete by title"에도 유사한
  반복 출력/안내 패턴이 있는지) 기회가 생기면, 이번엔 본인이 직접 함수를 뽑아내는지 관찰해서
  개념이 스킬로 이어졌는지 확인할 것.
- 이번 예외가 반복되면("몸 상태" 핑계로 대신 해달라는 패턴), 학습 목표(스스로 헤쳐나가는 능력)와
  충돌하니 다시 원칙으로 돌아가자고 짚어줄 필요가 있음.
