# 파일 I/O 기본 패턴과 디버깅 방식 확립

`json.load()`는 파일 이름(문자열)이 아니라 열린 파일 객체를 받아야 한다는 것을, `AttributeError: 'str' object has no attribute 'read'` 에러를 직접 읽고 스스로 고쳐서 이해했다. 이어서 "메모리에 이미 있는 변수를 왜 파일에서 다시 읽어오나"라는 질문을 받고, 중복된 파일 읽기 코드를 스스로 지우고 리팩터링했다.

**Implications**: 에러를 바로 고쳐주기보다 에러 메시지를 같이 읽고 질문으로 유도하는 방식이 이 학습자에게 잘 통한다 — Traceback을 스스로 해석해서 원인(`str`에는 `.read`가 없음)을 찾아냈고, 리팩터링 필요성도 유도 질문만으로 스스로 판단했다. 앞으로도 답을 바로 주지 말고, 관찰 포인트 → 질문 → (필요시) 설명 순서로 진행.
