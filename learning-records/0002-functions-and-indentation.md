# 함수 정의/호출과 들여쓰기 규칙 이해

`add_note(notes, title, content)` 함수를 직접 정의하고, `note.py`의 append 로직을 함수 호출로 교체했다. 그 과정에서 `IndentationError: unexpected indent`를 만났고, "들여쓰기는 코드가 어떤 블록에 속해있는지 나타낸다"는 설명을 들은 뒤 스스로 "들여쓰기 없어야 할 것 같다"고 정확히 판단해서 고쳤다.

**Implications**: 함수 정의(`def`/`return`)와 호출은 이해했다고 볼 수 있음 — 다음 레슨은 이를 활용한 약간 더 복잡한 구조(예: 여러 함수로 나누기, 인자 기본값, 또는 에러 처리)로 넘어가도 좋다. 들여쓰기 규칙도 실전에서 스스로 판단 가능한 수준.
