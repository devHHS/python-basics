# while True 메뉴 + 함수 반환값 개념 완전히 이해

`add_note`/`find_note`/`delete_note`를 `while True` + `if/elif` 메뉴로 묶었다. 처음엔 `search_title(title)`처럼
매개변수를 받아놓고 안 쓰거나, 호출 결과(return 값)를 변수에 안 담는 실수를 했지만, "함수 안에서 값을 밖으로
내보내려면 return, 호출한 쪽에서 그 값을 쓰려면 변수에 담아야 한다"는 설명을 들은 뒤 정확히 고쳤다.
switch(자바)와 while True의 차이(분기 vs 반복)도 질문을 통해 스스로 구분했다.

**Implications**: 함수의 매개변수(입력)와 반환값(출력)의 역할을 실전에서 헷갈렸다가 명확히 구분하게 됨 —
"이 함수가 뭘 받아야 하고 뭘 돌려줘야 하는지"를 설계 단계에서 먼저 생각하는 습관이 아직 약한 편이라,
다음에 새 함수를 만들 때는 그 부분을 먼저 질문해보는 게 좋을 듯. notes_app.py는 이제 추가/찾기/삭제/종료가
되는 완결된 CLI 노트 앱. 다음 단계는 여기서 죽은 코드(33~48번째 줄 주석, 78~80번째 줄) 정리, 또는
완전히 새로운 주제(예: 클래스/객체지향 맛보기, 여러 파일로 모듈 나누기)로 넘어갈 수 있음.
