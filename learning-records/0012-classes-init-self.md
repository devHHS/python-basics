# 0012 — 클래스, __init__, self

## 무엇을 했나
`class_practice.py`에 `Note` 클래스를 만들어보며 딕셔너리와 다른 "정해진 모양의 데이터" 문법을 익혔다.

```python
class Note:
    def __init__(self, title, content):
        self.title = title
        self.content = content

n1 = Note("장보기", "우유, 계란")
n2 = Note("자전거", "로드, MTB")
n1.content = "Quark, Tomaten"
```

## 겪은 실수와 fix
1. 인스턴스를 만드는 코드(`n = Note(...)`)를 `__init__` 함수 블록 안(들여쓰기 그대로)에 써서, "Note를 만들 때마다
   그 안에서 또 Note를 만드는" 코드가 됐다. 들여쓰기를 클래스 정의 바깥(맨 왼쪽)으로 빼서 해결.
2. `n.title`처럼 값만 써두고 `print()`를 안 써서 스크립트 실행 시 아무것도 안 보였다 — 터미널 스크립트 실행은
   REPL과 달리 표현식 값을 자동으로 보여주지 않는다는 걸 재확인.
3. 두 인스턴스를 모두 `n`이라는 같은 변수에 담아서 두 번째 대입이 첫 번째를 덮어썼다. 리스트로 여러 노트를
   담았던 것과 마찬가지로, 동시에 존재해야 하는 값은 각각 다른 이름(`n1`, `n2`)이 필요하다는 걸 스스로 짚어냈다.

## 확인한 개념
- `class`는 설계도, `__init__`은 인스턴스가 만들어질 때 자동 실행되는 초기화 함수 (관례상 "생성자"라고도 부르지만
  엄밀히는 파이썬의 진짜 생성 단계는 `__new__`이고 `__init__`은 초기화 단계임을 짚어줌)
- `self`는 `__init__`(과 다른 메서드) 안에서 "지금 이 인스턴스"를 가리키는 이름
- 인스턴스 속성은 딕셔너리 키와 달리 점 표기법(`n.title`)으로 접근하고, mutable해서 나중에 직접 재할당 가능
  (레슨 8의 "mutable 값 수정" 감각과 동일)
