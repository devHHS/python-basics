Reference

Python 기초 용어 사전

배운 용어를 여기에 계속 누적한다. 새 레슨에서 이 문서를 링크로 참조한다.

input()

프로그램을 멈추고 사용자가 키보드로 입력한 뒤 엔터를 칠 때까지 기다렸다가, 입력한 내용을 문자열(str)로 돌려준다.

title = input("제목이 뭔가요: ")

딕셔너리 (dict)

{key: value} 쌍으로 여러 값을 하나로 묶는 자료구조. 서로 관련 있는 값을 하나의 이름 아래 모을 때 쓴다.

note = {"title": title, "content": content}
note["title"]  # "제목"

리스트 (list)

[] 안에 값 여러 개를 순서대로 담는 자료구조. .append(x)로 끝에 추가한다.

notes = []
notes.append(note)

for문

리스트(또는 다른 순회 가능한 것) 안의 원소를 하나씩 꺼내서, 원소 개수만큼 반복 실행한다.

for n in notes:
    print(n["title"])

파일 열기 — with open(...) as f

open(경로, 모드)로 파일을 열고, with를 쓰면 블록이 끝날 때 자동으로 파일을 닫아준다. 모드: "r" 읽기, "w" 쓰기.

with open("notes.json", "r") as f:
    notes = json.load(f)  # f는 "열린 파일 객체" — 파일 이름(문자열)이 아니다

흔한 실수: json.load("notes.json")처럼 파일 이름을 직접 넘기면 AttributeError: 'str' object has no attribute 'read' 에러가 난다. json.load()는 열린 파일 객체가 필요하다.

json.dump / json.load

파이썬 자료구조(dict, list)를 파일에 저장하고 다시 불러오는 표준 라이브러리 함수.

json.dump(notes, f)   # 저장: notes를 f에 씀
notes = json.load(f)  # 불러오기: f에서 읽어서 돌려줌

함수 (def)

반복되거나 의미 단위로 묶을 수 있는 코드를 이름 붙여 재사용하는 방법. 레슨 1 참고.

def add_note(notes, title, content):
    notes.append({"title": title, "content": content})
    return notes

try / except

"일단 시도해보고, 특정 에러가 나면 처리한다"는 구조. try 블록에서 에러가 나면 프로그램이 멈추는 대신 except 블록으로 넘어간다. 레슨 2 참고.

try:
    with open("notes.json", "r") as f:
        notes = json.load(f)
except FileNotFoundError:
    notes = []

if / else, truth value testing

조건에 따라 다른 코드를 실행한다. 빈 문자열 "", 숫자 0, 빈 리스트 []는 파이썬에서 거짓(False)으로 취급된다. 레슨 3 참고.

title = input("제목: ").strip()
if title == "":
    print("제목을 입력해야 해요")
else:
    notes = add_note(notes, title, content)

.strip()

문자열 앞뒤의 공백(스페이스, 줄바꿈 등)을 제거하는 문자열 메서드. 사용자가 실수로 공백만 입력했을 때를 걸러낼 때 쓴다.

"  안녕  ".strip()  # "안녕"

while문

조건이 참인 동안 계속 반복한다. for문과 달리 몇 번 반복할지 미리 알 수 없을 때 쓴다. 조건에 쓰인 변수를 블록 안에서 갱신하지 않으면 무한 루프에 빠진다. 레슨 4 참고.

title = input("제목: ").strip()
while title == "":
    print("제목을 입력해야 해요")
    title = input("제목: ").strip()

enumerate()

리스트를 순회하며 (인덱스, 원소) 쌍을 하나씩 돌려준다. 원소를 지우거나 위치가 필요할 때 쓴다. 레슨 5 참고.

for i, n in enumerate(notes):
    print(i, n["title"])

del / 리스트에서 찾기

del notes[i]는 리스트의 i번째 원소를 지운다. 못 찾았을 때는 None을 돌려주는 관례를 쓴다.

def find_note(notes, title):
    for n in notes:
        if n["title"] == title:
            return n
    return None

def delete_note(notes, title):
    for i, n in enumerate(notes):
        if n["title"] == title:
            del notes[i]
            return notes
    return notes

while True / break / elif

while True:는 무조건 반복하며, break로 그 자리에서 빠져나온다. 조건이 여러 개면 elif로 이어 붙인다. 레슨 6 참고.

while True:
    choice = input("1.추가 2.찾기 3.삭제 4.종료: ").strip()
    if choice == "1":
        ...
    elif choice == "4":
        break
    else:
        print("잘못된 선택이에요")

None / is None

None은 "값이 없다"를 나타내는 특별한 값. 함수에서 return을 안 만나고 끝까지 실행되면 자동으로 None을 돌려준다. 어떤 값이 None인지 확인할 때는 == 대신 is를 쓰는 게 관례다. 레슨 7 참고.

found = find_note(notes, title)
if found is None:
    print("찾지 못했습니다")
else:
    print(f"찾았습니다: {found}")

함수 인자는 이름이 아니라 위치로 짝지어진다

함수를 호출할 때 넘긴 값은 def에 적힌 매개변수 이름이 아니라, 몇 번째로 썼는지(위치)로 짝지어진다. 그래서 호출할 때 순서를 잘못 넘기면, 변수 이름은 그럴듯해 보여도 함수 안에서는 완전히 다른 값이 된다.

def add_note(notes, title, content):
    ...

add_note(notes, title, content)  # notes→notes, title→title, content→content (올바름)
add_note(title, content, content)  # notes 자리에 title이 들어가버림 (틀림)

딕셔너리 값 바꾸기 (mutable 값 수정)

find_note가 돌려주는 건 복사본이 아니라 notes 리스트 안에 있는 바로 그 딕셔너리다. 그래서 찾은 걸 직접 바꾸면 원본도 같이 바뀐다. 레슨 8 참고.

def update_note(notes, title, new_content):
    n = find_note(notes, title)
    if n is None:
        return None
    n["content"] = new_content
    return n

여러 개 모아서 찾기 (return 대신 append)

find_note는 조건에 맞으면 바로 return해서 첫 번째 것만 찾고 멈춘다. 조건에 맞는 걸 전부 모으려면, 빈 리스트를 만들어두고 for문 안에서는 return 대신 append만 하고, 반복문이 다 끝난 뒤에 그 리스트를 리턴한다.

def find_all_by_title(notes, title):
    found_notes = []
    for n in notes:
        if n["title"] == title:
            found_notes.append(n)
    return found_notes

이 함수는 항상 리스트를 리턴하고 None은 절대 리턴하지 않는다. 그래서 "못 찾았는지" 확인할 때는 is None이 아니라 not found_notes(빈 리스트인지)로 확인해야 한다.

list.remove() / list.clear()

remove(값)은 del notes[i](인덱스로 지우기)와 다르게, 리스트 안에서 그 값과 같은 원소를 찾아 지운다. find_all_by_title처럼 원본 리스트 안의 딕셔너리를 그대로 담고 있는 리스트에서 하나를 골라, 그 딕셔너리 자체를 notes.remove(...)에 넘기면 원본에서 정확히 지워진다 (mutable 참조이기 때문). clear()는 리스트를 통째로 비운다.

chosen = found_notes[index]  # 사용자가 고른 딕셔너리 (notes 안의 것과 동일한 객체)
notes.remove(chosen)         # notes 안에서 그 딕셔너리를 찾아 지운다
notes.clear()                # notes를 통째로 비운다

모듈(module) / import

.py 파일 하나가 곧 모듈이다. from 모듈 import 함수1, 함수2는 함수 이름만 콕 집어서 가져오고, import 모듈은 모듈 전체를 가져와 모듈.함수()로 부른다. 레슨 9 참고.

from notes import add_note, find_note   # add_note(...) 로 바로 호출

import notes                            # notes.add_note(...) 로 호출

주의: 모듈 이름과 변수 이름이 같으면(import notes 후 notes = []처럼), 변수 대입이 모듈 이름을 덮어써서 AttributeError: 'list' object has no attribute '...'가 난다. 이럴 땐 from으로 필요한 이름만 가져오면 충돌이 안 생긴다.

클래스 (class) / __init__ / self

class는 "정해진 모양의 데이터"를 만드는 설계도다. __init__은 인스턴스를 만들 때 자동 실행되는 초기화 함수(관례상 생성자라고도 부름)이고, self는 그 안에서 "지금 만들어지는 바로 이 인스턴스"를 가리킨다. 딕셔너리와 달리 속성은 점 표기법으로 접근한다. 레슨 10 참고.

class Note:
    def __init__(self, title, content):
        self.title = title
        self.content = content

n = Note("장보기", "우유, 계란")
n.title            # "장보기" (딕셔너리처럼 n["title"]이 아니라 점 표기법)
n.content = "새 내용"  # 속성도 mutable — 나중에 다시 대입해서 바꿀 수 있다

메서드 (method)

클래스 안에 정의한 함수. 첫 매개변수는 항상 self이고, n.메서드()처럼 부르면 파이썬이 자동으로 self 자리에 인스턴스를 채워 클래스.메서드(n)으로 실행한다. self 뒤에 매개변수를 더 받을 수도 있다. 레슨 11 참고.

class Note:
    def __init__(self, title, content):
        self.title = title
        self.content = content

    def preview(self):
        return self.title + ": " + self.content[:10]

    def rename(self, new_title):
        self.title = new_title

n = Note("장보기", "우유, 계란")
n.preview()          # self=n 자동 전달 → "장보기: 우유, 계란"
n.rename("새 제목")   # self=n, new_title="새 제목"
n.title              # "새 제목"

ValueError

int()처럼 값을 변환하는 함수가, 타입은 맞지만 값 자체가 이상해서 변환에 실패할 때 던지는 에러. 글자, 대문자/소문자, 특수문자, 빈칸, 빈 문자열 등 "숫자로 못 바꾸는" 모든 경우가 전부 같은 ValueError 하나로 처리된다 — 원인별로 구분할 필요가 없다. 레슨 15 참고.

try:
    id = int(input("ID: ").strip())
except ValueError:
    print("숫자를 입력하세요.")
    continue

continue

반복문(while/for) 안에서, 그 아래 남은 코드를 건너뛰고 반복문의 처음으로 바로 돌아간다. if 몇 겹 안에 있든 상관없이, 자신을 감싸는 가장 가까운 반복문이 기준이다 — 들여쓰기 깊이가 아니라 "어떤 반복문에 속하는지"로 정해진다.

pytest / assert

파이썬에서 유닛 테스트(unit test)를 짜고 실행하는 도구. assert 조건은 조건이 참이면 아무 일도 없고, 거짓이면 AssertionError를 낸다. 파일 이름과 함수 이름이 모두 test_로 시작하면 pytest가 자동으로 찾아 실행한다. 레슨 16 참고.

# test_notes.py
from notes import next_id

def test_next_id_empty_list():
    assert next_id([]) == 1

실행은 pytest 파일명 또는 python -m pytest로 해야 한다. python3 test_notes.py처럼 스크립트로 직접 실행하면 함수 정의만 되고 아무것도 호출되지 않아 그냥 조용히 끝난다.

fixture (@pytest.fixture)

여러 테스트가 똑같이 반복하는 준비 코드(setup)를 함수 하나로 뽑아두는 pytest 기능. 테스트 함수의 매개변수 이름이 fixture 함수 이름과 같으면 pytest가 그 fixture를 실행한 결과를 자동으로 넣어준다. 필요한 테스트만 매개변수로 받으면 되고, 강제되지 않는다.

import pytest

@pytest.fixture
def sample_notes():
    return [{"id": 1, "title": "a", "content": "x"}]

def test_find_note_by_id_existing(sample_notes):
    assert find_note_by_id(sample_notes, 1) == {"id": 1, "title": "a", "content": "x"}

타입 힌트 (type hint)

매개변수와 반환값에 어떤 타입이 오가는지 코드에 적어두는 문법. 강제 규칙이 아니라 사람과 도구를 위한 약속이다 — 틀려도 실행은 된다. list[dict]처럼 대괄호로 컨테이너 안의 타입을, dict | None처럼 파이프로 "이거나 None"을 표현한다. 레슨 17 참고.

def find_note_by_id(notes: list[dict], id: int) -> dict | None:
    for n in notes:
        if n["id"] == id:
            return n
    return None
